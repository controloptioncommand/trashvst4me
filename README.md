# Burial Voice

VST3/AU-эффект для «призрачных» вокалов в духе Untrue: вокал, сдвинутый вверх или вниз
с отдельной ручкой формант, тихий голос октавой ниже, плавание плёнки, лоу-фай,
полосовой фильтр, тёмное даб-эхо, большой ревёрб и треск винила.

## Установка

### macOS (VST3 + AU)

1. Скачай `BurialVoice-macOS.zip` со страницы **Releases** и распакуй.
2. Правый клик по `Install Burial Voice.command` → **Открыть** → **Открыть**.
   Обычный двойной клик macOS заблокирует, потому что скрипт не подписан
   сертификатом Apple. Скрипт скопирует плагин в
   `~/Library/Audio/Plug-Ins/VST3` и `~/Library/Audio/Plug-Ins/Components`
   и снимет с него флаг карантина.
3. Перезапусти DAW. В Logic и GarageBand плагин будет в разделе
   Audio Units → Night Bus Audio, в Ableton, Reaper, FL и Bitwig — в VST3.

Сборка универсальная, работает и на Apple Silicon (M1–M4), и на Intel, macOS 10.13 и новее.

Если DAW всё равно пишет, что плагин повреждён или его нельзя проверить, выполни в Терминале:

```bash
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Burial Voice.vst3" ~/Library/Audio/Plug-Ins/Components/"Burial Voice.component"
```

### Windows / Linux

| Система | Куда положить папку `Burial Voice.vst3` |
|---|---|
| Windows | `C:\Program Files\Common Files\VST3\` |
| Linux | `~/.vst3/` |

Плагин работает в моно и стерео, вешается вставкой на вокальную дорожку.

## Ручки

**VOICE**
- **Pitch** (−12…+12 полутонов): высота голоса. Форманты при этом остаются на месте.
- **Formant** (−12…+12): тембр отдельно от высоты. Плюс даёт тонкий «женский» голос,
  минус — тёмный «мужской». Если Formant = Pitch, звучит как обычное ускорение сэмпла
  (тот самый «бурундучий» звук из старого Sound Forge). Если Formant в 1,5–2 раза меньше
  Pitch, получается бесполый голос, который тоже часто звучит на Untrue.
- **Shadow**: второй голос октавой ниже основного, тихий слой под ним.

**TEXTURE**
- **Wobble**: детонация плёнки (wow 0,55 Гц, flutter 6,8 Гц и медленный случайный дрейф).
- **Grit**: сатурация, а после 40 % ещё урезание частоты дискретизации и разрядности.
- **Crackle**: шипение, треск и редкие щелчки винила.

**TONE**: **Low Cut** / **High Cut**. Полосовой фильтр, чтобы голос звучал «издалека».

**SPACE**
- **Echo** / **Time**: тёмное эхо, повторы с каждым разом всё глуше. Правый канал
  чуть длиннее левого, это даёт ширину.
- **Space**: размер комнаты. **Reverb**: сколько её в звуке.

**OUT**: **Mix** (сухой/обработанный) и **Output** (громкость на выходе).

Двойной клик по ручке возвращает значение по умолчанию.

## Пресеты

| Пресет | Идея |
|---|---|
| Untrue | вокал +5, форманты +3, немного всего. Хорошая отправная точка |
| Angel Up | +7 вместе с формантами: высокий ускоренный сэмпл |
| Ghost Down | −5: низкий тёмный голос |
| Night Bus | +3 с Shadow, сильный вобл, узкая полоса, много эха и треска |
| Pirate Radio | грязный «радийный» звук с узкой полосой |
| Choir of One | +5 и громкий Shadow: сразу два голоса |
| Clean | всё выключено, сюда удобно начинать с нуля |

## Советы

- Лучше всего звучит на сухом вокале без своего ревёрба. Режь фразы на куски
  и раскладывай их по биту: эффект делает звук, а нарезку придётся делать самому.
- Задержка плагина около 50 мс. DAW компенсирует её сама, но живой мониторинг
  через плагин будет с задержкой.
- Mix подмешивает исходный голос ко всей обработанной цепочке, включая эхо и ревёрб.
  Количество хвоста удобнее регулировать ручками Reverb и Echo, а Mix держать на 100 %.

## Как устроено

- **Pitch и Formant**: фазовый вокодер (FFT 2048 при 44,1/48 кГц, перекрытие 75 %).
  Огибающая спектра считается кепстральным методом true envelope, порядок подстраивается
  под найденную высоту голоса. Пиковые регионы спектра сдвигаются целиком, с трекингом
  фаз по методу Laroche–Dolson.
- Офлайн-тест (`Tests/OfflineTest.cpp`) гоняет синтетическую гласную через обработку.
  Питч попадает с точностью до 0,1 %. При 0/0 сигнал проходит без потерь (SNR 80 дБ).
  При сдвиге питча форманты отклоняются от исходных на 2–5 дБ; если бы они ехали вслед
  за питчем, отклонение было бы 7–10 дБ.
- `Tests/MiniHost.cpp`: минимальный VST3-хост. Он загружает собранный бинарник,
  выводит параметры и пропускает через плагин звук.

## Сборка из исходников

Нужен JUCE рядом с проектом (папка `JUCE/`) или путь к нему в `-DBV_JUCE_DIR=...`.

```bash
# Linux
git clone --depth 1 --branch 7.0.12 https://github.com/juce-framework/JUCE.git JUCE
cmake -B build-linux -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build-linux
```

```bash
# Windows из Linux (нужен mingw-w64)
cmake -B build-win -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_TOOLCHAIN_FILE=cmake/mingw-w64-x86_64.cmake
cmake --build build-win
```

```bash
# macOS вручную (то же самое делает GitHub Actions: .github/workflows/build-mac.yml)
./build-mac.sh
```

На Windows можно собрать и через Visual Studio 2022 с JUCE 8: `cmake -B build -DBV_JUCE_DIR=путь\к\JUCE8`,
затем `cmake --build build --config Release`.
